Classify 隐私政策

生效日期：2026 年 10 月 1 日　　版本：V1.1　　出品方：Linkium DevTeam

Classify（以下简称"本软件"）坚持最小化收集原则。本政策说明本软件处理哪些信息、如何处理以及您的控制权。

一、我们收集与处理的信息
1. 账号信息：您自行设置的用户名与密码。密码经 PBKDF2 加盐哈希后仅以密文形式存储于云端服务中，我们与云端服务均无法还原明文。本软件不收集手机号、邮箱等任何个人身份信息。
2. 喊话内容：经云端中继时，喊话文本存储于设备收件箱，至设备确认接收或最长 24 小时后自动删除。
3. 文件与画面：经云端中继传输的文件存储于云端对象存储（R2），默认保留 7 天后由定时任务自动清理，您也可在网页端手动删除。教师主动触发的屏幕截图与摄像头照片会上传至教师端的文件列表，遵循同样的保留策略。
4. 剪贴板同步：仅在你主动触发（Ctrl+Alt+V 或托盘操作）时读取本机剪贴板文本并推送给已绑定的教师；教师推送的文本仅写入本机剪贴板，不做其他用途。
5. 语音合成：默认使用 Windows 本地语音引擎，文本不出设备。若您在设置中启用 Azure 神经语音，喊话文本将发送至微软 Azure 语音服务（区域默认 eastasia）用于合成语音，受微软隐私条款约束。
6. 域名解析：为保证连接可靠性，本软件使用 DNS over HTTPS（阿里 DNS / DNSPod / Cloudflare）解析服务域名，仅发送待解析的域名本身。
7. 设备信息：设备名称、随机生成的设备 ID、软件版本号、最近在线时间，仅用于设备列表展示与在线状态判断。
8. 自动更新：本软件定期检查更新清单，发现新版本时下载并校验（SHA-256）后安装，不携带任何额外数据。
9. 早读看板联动（可选）：若本机运行 EasiCareHelper（仅 127.0.0.1 回环通信），看板将从其读取学生名册并派发评价；该数据不经过云端。
10. 本软件不包含任何统计 SDK、广告组件或用户行为追踪。

二、信息的存储位置
1. 上述云端数据存储于 Linkium DevTeam 提供的或您自行部署的 Cloudflare Workers / KV / R2 / Durable Objects 服务中，存储区域由 Cloudflare 决定，您与 Cloudflare 之间的数据处理关系以 Cloudflare 的条款为准。
2. 本软件 V1.1 起已移除局域网直连通道，全部数据经云端中继传输。

三、本地数据
1. 本软件在 %AppData%\Classify 目录保存配置、日志与看板状态（含连接状态与错误信息），在桌面保存接收的文件。卸载软件不会自动删除这些文件，您可自行清理。
2. 旧版本（ClassCall Lite / ClassCallLite）的历史数据目录会在首次运行时自动迁移至新目录，迁移后旧目录不再使用。

四、您的控制权
1. 您可随时在网页端解绑设备、删除文件、注销不再使用的账号数据。
2. 设备令牌被解绑后立即失效。
3. 系统控制类指令（音量、锁屏、关机/重启）可在本机设置中逐项关闭；剪贴板同步亦可单独关闭。
4. 关闭 Azure 神经语音后，语音合成完全在本机完成，文本不再离开设备。

五、未成年人保护
本软件面向教师群体，应用于校园场景时，请勿通过本软件传输学生个人隐私信息；使用摄像头与屏幕回传功能时请遵守相关法律法规并获得必要同意。

六、政策更新
本政策可能随软件版本更新而修订，修订版随新版本一并发布，并在"关于"页展示当前版本。

七、联系方式
如对本政策有任何疑问，请联系 Linkium DevTeam。
