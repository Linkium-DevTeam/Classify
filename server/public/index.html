📌 常驻通知

与喊话不同：常驻通知会一直显示在教室大屏顶部灵动岛上，直到清除。

📷 教室照片

让教室电脑用前置摄像头（SmartCamera）拍一张照片回传，在下方文件列表查看。出于隐私考虑，设备端默认关闭此功能，需在教室电脑「设置 → 权限与隐私」中开启。

📖 早读智能看板

联动 EasiCareHelper（需在教室电脑运行）。学生在看板上按小组展示；加分模式与换算比例按你的账号设置生效。
